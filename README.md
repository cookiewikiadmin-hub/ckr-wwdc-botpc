## ✨ ทำอะไรได้บ้าง

### 🏃 วิ่งฟาร์มอัตโนมัติ
- วิ่งเก็บเหรียญ + XP **ต่อเนื่อง 24 ชม.** ไม่ต้องเฝ้า
- **จังหวะโดด/สไลด์เหมือนคนจริง** (สุ่มหน่วง จับทางยาก)
- โดดตอนเริ่ม / โดดตลอดรอบ / โหมดวิ่งเปล่า — เลือกได้
- เฝ้าพลังชีวิต (ภูติอัคคี) + เฝ้าสกิล (คุกกี้มันบด) อัตโนมัติ

### 🖥️ หลายจอพร้อมกัน
- คุม **MuMu / LDPlayer หลายจอ**ในหน้าต่างเดียว
- ตั้งค่าแยกรายจอ หรือใช้ค่ากลางร่วมกัน
- **จัดเรียง + ปรับขนาดจอ**ให้เองอัตโนมัติ
- **พรีวิวจอสด** เห็นทุกจอแบบเรียลไทม์

### 🛒 ซื้อบูสต์ + ไอเทมอัตโนมัติ
- ซื้อ **Fast Start / Cookie Relay (ไม้ 2)** ให้ทุกรอบ + กดใช้ให้
- **Multi-Buy** + บูสต์มาตรฐาน + **Power+** ตั้งค่าได้ละเอียด
- กดใช้ไม้ 2 แล้วออกจบรอบ (วิ่งคุ้มที่สุด)

### 🎴 แก้มินิเกมการ์ดอัตโนมัติ
- เจอ **"Surprise! Find the card"** → **หา 2 ใบที่ถูกแล้วแตะให้เอง** (ไม่ค้าง)
- ใช้การเทียบรูปการ์ด ไม่ว่าคุกกี้แบบไหนก็แก้ได้

### 💎 ฟาร์มสมบัติครบวงจร (ย่อยผง)
- **ย่อยผง · ตีบวก · Evolution · ย่อยขั้นสุดท้าย** ครบทุกขั้น
- เลือกสมบัติ + ตั้งระดับเป้าหมายรายชิ้น
- คำนวณความคุ้มค่า + สถิติรายชนิด

### 🎁 ระบบเสริมเต็มพิกัด
- **เปิดกล่องปริศนา** + นับกล่องที่ได้
- **รับ/ส่งหัวใจ** + คัดเพื่อนที่ไม่ส่งใจออก
- **Gift Draw** อัตโนมัติ
- **คืนทีมคุกกี้เดิมหลังได้ Legendary**
- รับรีลิก (Relic) อัตโนมัติ

### ⚙️ ควบคุม + ปลอดภัย
- **ตั้งเงื่อนไขหยุดเอง** — ครบจำนวนรอบ / ครบเวลา / เหรียญถึงเป้า
- **กู้คืนอัตโนมัติ**เมื่อเกมค้าง (รีสตาร์ตเกมเอง)
- **ล็อกอินเกมใหม่อัตโนมัติ** (รองรับรหัสคนละตัวต่อจอ)
- **แจ้งเตือน Telegram / Discord** เมื่อมีเหตุ

### 📊 สถิติ + พรีเซ็ต
- รายงาน **เหรียญ/ชม. · XP/ชม. · คาดการณ์ 24 ชม.** รายจอ
- บันทึก/โหลด **พรีเซ็ต**การตั้งค่า แชร์กันได้
- ประวัติรอบ + ตั๋ว + กล่องที่ได้
